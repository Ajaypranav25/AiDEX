# Setup components

Shared installer building blocks composed from `@aidex/ui`: `ComponentChecklist` (a catalog group as checkboxes with sizes) and `SpaceSummary` (estimated size against the chosen drive's free space). The wizard frame itself (`WizardLayout`, `WizardFooter`, `Stepper`) lives in `@aidex/ui/installer`. Keep capability status explicit: drive provisioning, model transfer, agent setup, encryption, and installation are not available in this app yet.

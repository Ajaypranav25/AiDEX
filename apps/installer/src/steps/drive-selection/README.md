# Drive step

Step 1: choose the target from the real volume list (`list_drives`, via `../../lib/useDrives.ts`) with label, root, attachment (removable, USB fixed disk, internal), filesystem, and free/total space. The system drive, internal disks, and unclassified volumes are shown but cannot be chosen; existing AiDEX drives are badged with their schema. AiDEX installs at the drive root next to existing files. "Rescan drives" lists volumes again.
